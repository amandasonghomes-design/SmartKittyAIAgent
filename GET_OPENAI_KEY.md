# 🔑 How to get your OpenAI API key (5 minutes, start with just $5)

Smart Kitty (an **Android phone app**) needs an **OpenAI API key**: a private password that lets the app talk to
OpenAI's AI for you. Getting one is easy, even if you've never done anything "technical".

## 💡 First: a ChatGPT subscription is NOT the same as the API

| | ChatGPT Plus / Pro | OpenAI API (what Smart Kitty uses) |
|---|---|---|
| Where | chatgpt.com app and website | Apps like Smart Kitty |
| How you pay | Monthly subscription | **Pay as you go: no subscription** |
| Minimum | Fixed monthly price | **$5 one time**, top up only when you want |

Even if you already pay for ChatGPT Plus, the API is **billed separately**: your subscription
doesn't include it ([OpenAI's help page](https://help.openai.com/en/articles/8156019-is-api-usage-included-in-chatgpt-plus)).
You can use the **same login** as ChatGPT, though.

### Why it's a great deal 🎉

- **No monthly fee.** You only pay for what you actually use.
- **Start with just $5.** That's the minimum, and it lasts a long time.
- **Super cheap with the default model.** Smart Kitty uses `gpt-6-luna`, OpenAI's most affordable
  model. A normal chat message costs **about a tenth of a cent**, so **$5 is thousands of messages**.
- **You're always in control.** When your credit runs out, it simply stops. No surprise bills
  (if you turn off auto-recharge, step 6 below).
- Check exactly what you've spent anytime in Smart Kitty's **Settings → Usage**, or on OpenAI's website.

> Making pictures and web searches cost a bit more than chatting, but still only cents.
> Credits expire after 1 year.

## Step-by-step

You can do all of this **on your phone**, which makes copying the key into the app easiest.

### 1. Sign in
Go to **https://platform.openai.com** and sign in. You can use your ChatGPT account
(or "Continue with Google"). New here? Tap **Sign up** and verify your email and phone.

### 2. Add $5 of credit
1. Open **https://platform.openai.com/settings/organization/billing**
   (or tap your profile/⚙️ **Settings → Billing**).
2. Tap **Add payment details** and enter your card.
3. Choose the amount: **$5 is enough to start**. The default is $10.
4. Wait a few minutes for the credit to show up.

### 3. Create your key
1. Open **https://platform.openai.com/api-keys**.
2. Tap **Create new secret key**.
3. Give it a name like `smart kitty`, keep the default settings, and tap **Create secret key**.
4. Tap **Copy**. ⚠️ OpenAI shows the key **only once**. If you lose it, just make a new one.

The key is a long code that starts with `sk-`.

### 4. Paste it into Smart Kitty
1. Open Smart Kitty and tap **Settings**.
2. Paste the key into **OpenAI API key**, then tap **Save**.
3. Say "hi" to your kitty! 🐱

### 5. Keep your key secret 🔒
- **Never** post it online, put it in a screenshot, or paste it into a chat or email.
  Anyone who has it can spend your credit.
- Smart Kitty stores it **encrypted** on your phone, and it is never sent anywhere except OpenAI.
- If you think someone saw it: go to **API keys**, tap the 🗑 trash icon to delete it, and create a new one.

### 6. (Recommended) Turn off auto-recharge
OpenAI turns on **auto-recharge** by default when you add a card, which refills your credit
automatically. To make sure you never spend more than you planned:
**Billing → Auto recharge → turn it off** (or set a monthly limit).
Then you simply top up by hand whenever you want.

## ❓ Common problems

| You see | What to do |
|---|---|
| "You exceeded your current quota" / "insufficient quota" | Your credit is $0, or the payment is still processing. Add credit in **Billing** and wait a few minutes. |
| "Incorrect API key" | The key was copied incompletely or deleted. Create a new key and paste it again. |
| I added credit but it still fails | Check the **organization name** at the top-left of platform.openai.com. Your credit and your key must be in the **same** organization. Create the key there. |

Prefer a video? Search YouTube for **"how to get OpenAI API key"**. The steps are the same.
OpenAI's own guide: [Prepaid billing](https://help.openai.com/en/articles/8264644-setting-up-and-managing-prepaid-api-billing).

## 🇨🇳 中文简要版：如何获取 OpenAI API 密钥

**注意：ChatGPT Plus 会员 ≠ API。** 即使你已经订阅了 ChatGPT Plus，API 也是**单独计费**的。
但 API **没有月费**，**按用量付费**，**最低只需充值 5 美元**就能开始！
Smart Kitty 默认使用最便宜的 `gpt-6-luna` 模型，普通聊天每条大约只要 **0.1 美分**，5 美元可以聊**几千条**。

1. 打开 **https://platform.openai.com** 登录（可以用 ChatGPT 账号或 Google 账号）。
2. 进入 **Billing（账单）** → **Add payment details（添加付款方式）** → 充值 **$5**。
3. 打开 **https://platform.openai.com/api-keys** → **Create new secret key（创建新密钥）** → **Copy（复制）**。
   ⚠️ 密钥只显示一次，丢了就重新建一个。
4. 打开 Smart Kitty → **Settings（设置）** → 粘贴到 **OpenAI API key** → **Save（保存）**。
5. 🔒 密钥千万不要发给别人、不要截图、不要贴到网上。被看到了就删掉重新建一个。
6. 建议在 **Billing → Auto recharge（自动充值）** 里关掉自动充值，这样永远不会超支。
